# 0.1.0: initialize

VERSION: `0.1.0`

First commit of working code. Nothing here searches the web yet.

- .NET 10 solution with the `ai-hero-rat` global tool (package id and command name `ai-hero-rat`).
- `ai-hero-rat serve` starts an MCP server on stdio. It exposes no tools. Stdout carries only JSON-RPC; logs go to stderr.
- `ai-hero-rat version` prints the bare version.
- Commands are parsed with Spectre.Console.Cli.
- xunit.v3 tests, including an integration test that checks `serve` keeps stdout clean.
- lefthook hooks, a GitHub Actions build workflow, and the first ADR.

The package is not published to nuget.org.
