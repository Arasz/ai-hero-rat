# 0.2.0: search secrets

VERSION: `0.2.0`

The tool can now read search API keys. It still exposes no search tools.

- `ai-hero-rat serve` loads the tool's .NET user-secrets store (id `ai-hero-rat-c3af1c6c`) into its configuration. A missing store is fine.
- Keys are named `Search:ApiKey:Brave`, `Search:ApiKey:Exa` and `Search:ApiKey:TinyFish`.
- `scripts/copy-search-secrets.sh [source-id]` copies the `Search:ApiKey:*` entries from another project's user-secrets store. Values go through a pipe; only key names are printed.

To use it, put your keys in the store, either with `dotnet user-secrets set ... --id ai-hero-rat-c3af1c6c` or with the script.
