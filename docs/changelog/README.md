# Changelog

Each release gets one file named `{version}-{slug}.md`, for example `0.1.0-initialize.md`.
The version matches the repo-root [`VERSION`](../../VERSION) file at the time of release.

A good entry says what changed, in plain words, and names anything a user has to do about it.
Keep it short.
